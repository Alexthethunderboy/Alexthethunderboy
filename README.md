## Cybersecurity learning & projects

**NetCore — DHCP, routing and selective traffic filtering.** Educational Cisco Packet Tracer coursework modelling IT, Sales and HR across three /24 networks. Router-based DHCP supplies six PCs; an inbound Sales ACL blocks Sales-originated ICMP echo requests to IT while preserving replies for IT-initiated pings. Recorded live tests on 9 October 2026 matched ten expected traffic outcomes, including HTTP and FTP. Reopening and retesting the saved project remains unverified. These unencrypted lab services and permissive ACL are not a production-security design. An original case study is being prepared for review.
